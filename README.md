# Python Job-Ready

A progress log of my 8-week plan to become job-ready in Python. Each `weekN/` folder holds the code I wrote that week. Written and tested with Python 3.13.

## Week 1: Fundamentals
- Variables, types, control flow, strings, collections, functions
- An age-category script with input validation, a sentence analyzer (word count, reverse, vowel removal), and a dedupe-and-count function that preserves order
- **Can now:** write and debug small scripts, and explain `return` vs `print`

## Week 2: OOP and first algorithms
- `BankAccount` and `SavingsAccount` (inheritance with `super()`), plus a custom `InsufficientFundsError`
- Two Sum in O(n) with a hash map, valid anagram, and a `Stack` class with a custom `StackEmptyError`
- Git branching and resolving a merge conflict by hand
- **Can now:** design small classes, raise and catch custom exceptions, and solve hash-map problems

## Week 3: Algorithms and complexity
- Big O, binary search, bubble sort with an early-exit optimization and a step-by-step terminal visualizer
- Factorial and Fibonacci, both recursive and iterative
- Merge two sorted lists, first non-repeating character, valid parentheses (stack-based)
- `git stash` and `git rebase`
- **Can now:** state the time and space complexity of my solutions and spot hidden O(n²) code

## Week 4: Files, packages and APIs
- Reading and writing files, CSV cleaning, word-frequency counting
- Virtual environments, `pip` and `requirements.txt`
- Calling web APIs with `requests` and parsing JSON (joke fetcher, weather CLI using Open-Meteo)
- **Expense tracker:** a command-line app with add, view, delete, category totals, monthly summary and JSON storage. It backs up a corrupted data file instead of overwriting it. It lives in its own repo: [Expense_tracker](https://github.com/Darsh02-12/Expense_tracker)
- **Can now:** build a small command-line tool that saves data and handles bad input

## Week 5: Intermediate DSA (in progress)
- Two-pointer pair-with-sum, fixed-size sliding window, longest substring without repeating characters
- **Next:** linked lists and an introduction to `pytest`
